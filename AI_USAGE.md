# Использование генеративного ИИ

OpenAI Codex (Sol-5.6) применялся точечно как вспомогательный инструмент. Он использовался для технических формулировок, поиска идей и подбора дополнительных тестовых случаев.

## Как была разделена работа

| Направление | M1 | M2 |
| --- | --- | --- |
| Документация | Использовал подсказки для проверки понятности формулировок об авторизации, доступе к объектам и защите данных. Затем сверял текст с API и реализацией. | Проверял итоговые формулировки о целостности данных, конкурентной регистрации и аудите по коду и тестам. Для этой части подсказки ИИ не использовал. |
| Тестирование | Рассматривал предложенные пограничные случаи для токенов, ролей, черновиков и доступа к чужим объектам. В тесты включались только воспроизводимые сценарии. | Рассматривал предложенные сценарии конкурентного доступа, rollback, ограничений БД и аудита. Каждый сценарий проверялся по состоянию БД и ожидаемому требованию. |
| Рефакторинг | Проверял изменения в коде авторизации, схемах ответа и зависимостях, чтобы они не меняли правила доступа. | Проверял изменения в транзакционной логике регистрации и отмены, чтобы сохранялись атомарность и инварианты данных. |

ИИ не принимал решения вместо команды и не считался источником доказательств.
