# Campus Events

Campus Events — учебный Web API для публикации мероприятий и регистрации участников с ограниченным числом мест.
Проект команды **DoubleBug** подготовлен по курсу РБПО.

## Возможности

- Organizer создаёт, редактирует, публикует и отменяет свои мероприятия.
- Participant просматривает опубликованные мероприятия, регистрируется и отменяет свою регистрацию.
- Число активных регистраций не превышает вместимость даже при одновременных запросах.
- Черновики, чужие мероприятия, регистрации и списки участников защищены объектной авторизацией.
- Значимые изменения фиксируются в журнале аудита.
- Пароли хранятся как Argon2-хеши, а доступ к защищённым маршрутам выполняется по JWT.

## Технологии

- Python 3.12+
- FastAPI и Pydantic
- SQLAlchemy и SQLite
- PyJWT и pwdlib/Argon2
- pytest и pytest-cov

## Запуск и проверка

Полная инструкция для Linux, macOS и Windows, требования к переменным окружения и учебные аккаунты приведены в разделе
[«Локальный запуск» паспорта проекта](PROJECT.md#10-локальный-запуск).

После установки зависимостей тесты запускаются командой:

```bash
python -m pytest
```

Ожидаемый результат: 29 успешно выполненных тестов и 100% покрытия строк и ветвей приложения.

При запущенном API доступна сквозная демонстрация:

```bash
python scripts/demo.py
```

Ожидаемый результат: `26/26 checks passed`. Health-check доступен по адресу
[`http://127.0.0.1:8000/health`](http://127.0.0.1:8000/health), Swagger UI — по адресу
[`http://127.0.0.1:8000/docs`](http://127.0.0.1:8000/docs).

## Основные маршруты

| Метод и путь | Доступ | Назначение |
| --- | --- | --- |
| `GET /health` | Все | Проверка работоспособности |
| `POST /auth/login` | Все | Получение JWT |
| `GET /events`, `GET /events/{id}` | Все | Просмотр опубликованных мероприятий |
| `POST /events` | Organizer | Создание черновика мероприятия |
| `PATCH /events/{id}` | Organizer-владелец | Изменение своего мероприятия |
| `POST /events/{id}/publish` | Organizer-владелец | Публикация мероприятия |
| `POST /events/{id}/cancel` | Organizer-владелец | Отмена мероприятия и активных регистраций |
| `GET /events/{id}/participants` | Organizer-владелец | Просмотр списка участников |
| `GET /events/{id}/audit` | Organizer-владелец | Просмотр журнала изменений |
| `POST /events/{id}/registrations` | Participant | Регистрация на мероприятие |
| `GET /my/registrations` | Participant | Просмотр своих регистраций |
| `POST /registrations/{id}/cancel` | Participant-владелец | Отмена своей регистрации |
